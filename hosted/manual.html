ProcureFlow User Manual

Farmer procurement scheduling, queue tracking and support · Version 1.5 · 10 September 2026

← Return to ProcureFlow

1. Quick start

  1. Open ProcureFlow and choose Farmer, Centre staff or Administrator on the sign-in screen.
  2. Press the matching demo account, then Sign in.
  3. Use the top navigation on desktop or bottom navigation on Android.
  4. Choose English, हिन्दी or मराठी from the language selector.
No ChatGPT login is required. ProcureFlow has its own role-based demonstration sign-in.

2. Roles

Farmer
Find centres, compare queue load, verify eligibility, book a token, recover a missed slot and contact support.
Centre staff
View load and advance the live procurement journey from check-in to payment.
Administrator
Monitor centres, manage schedules, explore records, send alerts and answer live chats.

3. Farmer workflow

Choose a centre

Compare distance, available slots and estimated wait. The highlighted recommendation is the least-congested practical option.

Book a token

  1. Open Schedules and press Check eligibility.
  2. Select centre and time, enter quantity, and confirm ID, bank and land/tenancy declarations.
  3. Press Confirm and book token. The dashboard shows token, position and ETA.

Track the journey

Booked → Arrived → Gate check-in → Weighing → Quality check → Accepted → Payment processing → Payment completed.

Missed slot

Choose I missed my slot, select an offered centre/time and confirm rebooking.

4. ProcureBot and live admin chat

Open Support. ProcureBot gives instant rule-based answers about booking, documents, queue ETA, missed slots, payments and languages. It does not require an AI account.

Choose Live admin chat to talk to an administrator. Messages display the sender’s name and are stored on the hosted service. Sent messages show Seen ✓✓ after the other side opens them.

  • Press ＋ to attach a photo, short video or audio file (maximum 12 MB).
  • Press ●, allow microphone access, speak, then press it again to attach a voice note.
  • Use Edit on your own text. Use Delete to remove a message; admins may moderate any message.
  • A short sound plays for a new incoming message after the user has interacted with the page.
Hackathon security note: this build uses demo identities. A production rollout should connect government identity authentication, retention policy, consent logging and malware scanning.

5. Administrator chat

  1. Sign in as Administrator and open Live chat.
  2. Select a named farmer/staff conversation in the left panel. The unread badge shows pending messages.
  3. Reply with text or media. Opening the thread marks received messages as seen.
  4. Use Edit for your own text or Delete for moderation.

6. Install the Android app

  1. Open the public HTTPS site in Chrome on Android.
  2. Press Install app in ProcureFlow when available, or Chrome menu → Add to Home screen.
  3. Launch ProcureFlow from the home-screen icon. Core screens remain available from cache; live queue, chat and alerts need internet.

7. Notifications and SMS

In Messages, Enable phone alerts grants browser-notification permission. The custom alert appears in-app and on that device. Send preset SMS demonstrates Twilio trial delivery; production custom SMS in India must use an approved sender/template and comply with applicable DLT rules.

8. Troubleshooting

  • Chat does not load: reconnect to the internet, refresh and sign in again.
  • Microphone blocked: use the browser site controls to allow microphone access.
  • Install button missing: use Chrome’s Add to Home screen option.
  • No notification sound: interact with the page once and ensure the device is not muted.
  • Large media rejected: compress it below 12 MB.
